1) نزّل Node.js (22 او احدث) من nodejs.org
2) في CMD:  winget install yt-dlp   ثم   winget install Gyan.FFmpeg   (وسكّر CMD وافتحه من جديد)
3) افتح tokens.txt وحط كل توكن بسطر (بدون علامات تنصيص). تقدر تحط 1 او 10 بوتات
4) شغّل start.bat  (او:  npm install  ثم  node index.js)

الاوامر (لكل البوتات نفس الاوامر):
  !start ID   -> اول بوت فاضي يدخل الروم
  !song الرابط -> يشغّل في البوت اللي بنفس رومك (ادخل الروم اول)
  !stop       -> البوت اللي بنفس رومك يطلع
لازم كل البوتات تكون مضافة للسيرفر وفعّل Message Content Intent لكل واحد
